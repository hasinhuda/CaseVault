# Security Assurance Evidence

This directory stores threat models, security architecture reviews, testing plans, static analysis justifications, and compliance mappings (e.g. ASVS, OWASP Top 10) for CaseVault.
All claims must be backed by reproducible test evidence or source artifacts.
