# Security Assurance Evidence

This directory stores threat models, security architecture reviews, testing plans, and compliance mappings (e.g. ASVS, OWASP Top 10) for CaseVault.
All claims must be backed by reproducible test evidence or source artifacts.

## Assurance Documents

- [Trivy Vulnerability Scan Assessment](trivy.md): Analysis of CI container/dependency scan findings, upgrade resolutions, and accepted non-exploitable CVE exemptions.
